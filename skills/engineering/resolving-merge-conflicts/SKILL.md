---
name: resolving-merge-conflicts
description: "当你需要解决进行中的 git merge/rebase 冲突时使用。"
---

1. **查看 merge/rebase 的当前状态**。检查 git 历史，以及冲突的文件。

2. **为每个冲突找到 primary source**。深入理解每处改动为何而做、原始意图是什么。读提交信息，查看 PR，查看原始 issue/工单。

3. **解决每个冲突块**。尽可能保留双方意图。互不兼容时，选择符合本次合并既定目标的一方，并记下取舍。禁止发明新行为。总是解决到底；禁止 `--abort`。

4. 找出项目的**自动化检查**并运行——通常是类型检查，然后测试，然后格式化。修好合并弄坏的任何东西。

5. **完成 merge/rebase。** 暂存所有内容并提交。如果是 rebase，继续 rebase 流程直到所有提交都完成变基。
