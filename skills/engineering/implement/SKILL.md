description: "基于规格说明、计划或一组工单实现一项工作。"

实现用户指定的工作：优先按 `plans.md` 中的任务执行；没有计划时，按 `spec.md`、`handoff.md` 或工单描述推进。

## 逐任务执行

对每个任务（来自 `plans.md`，或从 spec/handoff/工单拆出）：

1. 宣布："正在处理任务 N：[描述]"
2. 引用规格或设计："Spec 说 X，所以我做 Y"
3. 只在事先约定的 seam 处用 `/tdd` 完成 red → green
4. 运行该任务相关的测试与类型检查
5. 在 `plans.md` 或 ticket 中标记完成：`- [ ]` → `- [x]`
6. 简要状态："✓ 任务 N 完成"

计划与实现不符时，先向用户说明偏差和理由，更新 `plans.md` 后再继续；禁止静默偏离已批准的计划。

所有任务完成后，报告已完成的任务清单和简要总结；评审和验证通过前，禁止宣称变更已实现。

## 收尾

1. 运行完整测试套件，修复所有失败。
2. 用 `/code-review` 审查这项工作。
3. 宣称成功之前，用 `/verification-before-completion` 验证。
4. 评审和验证通过后，询问用户是否将工作提交到当前分支。
