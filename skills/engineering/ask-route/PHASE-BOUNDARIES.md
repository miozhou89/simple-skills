# 阶段边界

**阶段（phase）** 是会话中的一块工作——访谈、实现、QA。这个定义故意保持模糊：当你心想 *「好了，那块做完了」* 时，一个阶段就结束了。

**阶段边界**是两个阶段之间的缝隙，也是唯一适合做这项决策的地方。阶段进行中没有决策可做——要么继续，要么把剩余工作拆给 subagent。在阶段进行中 compact 会让 agent 断掉思路。

## 五个选项

| 选项       | 作用                                                    |
| ------------ | --------------------------------------------------------------- |
| **Continue** | 留在当前会话。完全不切换上下文。                    |
| **`/clear`** | 清空上下文窗口，从零开始。                  |
| **`/handoff`** | 写一份可移植的 markdown 文件，用它给任意位置的会话做种子。 |
| **Subagent** | 把任务送进它自己的上下文窗口，拿回一份报告。     |
| **`/compact`** | 压缩当前上下文，用摘要给一个新会话做种子。  |

## 决策树

在边界处自上而下地走。第一个**是**胜出。

**1. 你能在当前会话中继续吗？** 两种情况让答案为是：下一阶段需要把这一阶段当作 **primary source**，或者你的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone) 还剩足够余量（约 150k tokens）装得下下一阶段。访谈 → 实现是标准的「是」：实现需要的是原汁原味的推理，而不是它的摘要。Continue 零成本零损失，所以要先于一切把它排除掉。

**2. 这里的上下文对接下来无关紧要吗？** 这个会话里的一切——探索、决策、死胡同——都可以丢弃吗？如果是，**`/clear`**。它是棋盘上最便宜的一步：不花时间，还归还整个窗口。`/clear` 也不是终局——旧会话仍可恢复。

做错的代价是单向的。清掉一个*相关*的上下文，你就失去了构建物背后的 **why**，再怎么回读 diff 也找不回来。

**3. 你需要交接吗？** `/handoff` 的适用面很窄。只有当你在以下情况时才需要它：

- 换到**新 harness**（Claude → Codex），
- 移到**新目录**或新 repo，
- 把工作交给**同事**，
- 或在**阶段进行中**分叉出一个支线任务，又不想打乱手头的事。

这个列表就是全部条款。`/handoff` 换来的是**可移植性**——一份可携带的文件。如果没有内容需要携带，你就不需要它。

**4. 这个任务能 AFK 完成吗？** 它的范围是否收紧到可以在你离开键盘、无人操舵的情况下运行？那就把它发给 **subagent**，让本会话原封不动。自动化评审是标准用例：agent 读 diff 并汇报，这期间不需要你。

**5. 否则，`/compact`。** 上下文相关、同一个 harness、同一个目录、而且你需要留在环中——决策树就落在这里，而且经常落在这里。给它传一句指令（`/compact 我们要 QA 这块区域`），好让摘要保留下一阶段需要的东西。

`/compact` 是**默认项，不是第一选择**。它位于底部，是因为上面四个问题全都更便宜或更精确。从这里开始的失败模式是：新会话对一个已被摘要抹平的决策自信满满地犯错。

## Primary 与 secondary sources

除 **Continue** 之外的每一步，都是把 **primary source** 变成 **secondary source**——会话的实况，被它的摘要取代。这笔交换的形状总是相同：

| 来源                            | 信息量 | 噪音 | 回旋余地 |
| --------------------------------- | ----------- | ----- | ------------ |
| Primary（Continue）                | 完整        | 多  | 小       |
| Secondary（`/compact`、`/handoff`） | 有损       | 少  | 大         |

这就是为什么问题 1 排在最前。只有当「留下」的代价大于它的收益时，你才该付这份有损的代价。

## 这些是判断力问题

这些问题并不客观——每一个都带着品味成分，同一个边界在两天里可能走向两边。价值在于**按顺序**问它们，在边界处问，而不是在工作进行到一半时问。
