# 技能：工业粗野主义与战术遥测 UI

## 1. 视觉原型
该设计系统通过融合两种截然不同但高度兼容的视觉范式来运作。**每个项目选择一个并坚持使用。禁止在同一界面内交替或混用这两种模式。**

### 1.1 瑞士工业印刷
源自 1960 年代的企业形象识别系统与重型机械蓝图。
*   **特征：**高对比度的 light mode（新闻纸/米白基底）。依赖整体式、粗重的 sans-serif 字体。由可见的分隔线勾勒出毫不妥协的结构 grid。激进、不对称地使用留白，并以超大、溢出 viewport 的数字或字母点缀。大量使用原色红作为警示/强调色。

### 1.2 战术遥测与 CRT 终端
源自机密军事数据库、老式大型主机以及航空航天抬头显示器（HUD）。
*   **特征：**仅限 dark mode。高密度的表格化数据呈现。monospace 排版占据绝对主导。整合技术性框定装置（ASCII 方括号、十字准线）。应用模拟的硬件限制（磷光辉光、扫描线、低位深 render）。

## 2. 排版架构
排版是主要的结构性与装饰性基础设施。图像是次要的。该系统要求在字号、字重和间距上具备极端的差异。

### 2.1 宏观排版（结构性标题）
*   **分类：**新怪诞体 / 粗重 sans-serif。
*   **最优 Web 字体：**Neue Haas Grotesk (Black)、Inter (Extra Bold/Black)、Archivo Black、Roboto Flex (Heavy)、Monument Extended。
*   **实现参数：**
    *   **字号：**使用流体排版部署到超大字号（例如 `clamp(4rem, 10vw, 15rem)`）。
    *   **tracking（letter-spacing）：**极其紧凑，常为负值（`-0.03em` 到 `-0.06em`），迫使字形形成坚实的建筑体块。
    *   **leading（line-height）：**高度压缩（`0.85` 到 `0.95`）。
    *   **大小写：**仅使用大写，以形成结构性冲击力。

### 2.2 微观排版（数据与遥测）
*   **分类：**monospace / 技术型 sans-serif。
*   **最优 Web 字体：**JetBrains Mono、IBM Plex Mono、Space Mono、VT323、Courier Prime。
*   **实现参数：**
    *   **字号：**固定且小（`10px` 到 `14px` / `0.7rem` 到 `0.875rem`）。
    *   **tracking：**宽松（`0.05em` 到 `0.1em`），以模拟机械打字机间距或终端矩阵。
    *   **leading：**标准到紧凑（`1.2` 到 `1.4`）。
    *   **大小写：**仅使用大写。用于所有元数据、导航、单元 ID 与坐标。

### 2.3 纹理对比（艺术性破坏）
*   **分类：**高对比度 serif。
*   **最优 Web 字体：**Playfair Display、EB Garamond、Times New Roman。
*   **实现参数：**极其克制地使用。必须经过大量后处理（半调滤镜、1 位抖动），以降低矢量完美度，并与干净的 sans-serif 形成纹理上的并置对比。

## 3. 色彩系统
色彩架构毫不妥协。gradient、柔和 shadow 和现代半透明效果被严格禁止。色彩模拟物理媒介或原始的发光显示器。

**关键：每个项目选择一种基底色板并始终一致地使用。禁止在同一界面内混用浅色与深色基底。**

### 若为瑞士工业印刷（浅色）：
*   **背景：**`#F4F4F0` 或 `#EAE8E3`（哑光、未漂白的文档纸）。
*   **前景：**`#050505` 到 `#111111`（碳墨色）。
*   **强调色：**`#E61919` 或 `#FF2A2A`（航空/危险红）。这是唯一的强调色。用于删除线、粗结构分割线或关键数据高亮。

### 若为战术遥测（深色）：
*   **背景：**`#0A0A0A` 或 `#121212`（已关闭的 CRT。避免纯 `#000000`）。
*   **前景：**`#EAEAEA`（白色磷光）。这是主要文本颜色。
*   **强调色：**`#E61919` 或 `#FF2A2A`（航空/危险红）。同样的红，同样的规则。
*   **终端绿（`#4AF626`）：**可选。只用于单个特定 UI 元素（例如一个状态指示器或一个数据读数）——禁止用作通用文本颜色。若没有明确用途，则完全省略。

## 4. layout 与空间工程
layout 必须呈现数学化工程的观感。它摒弃传统的 Web 内边距，转而采用可见的分区化。

*   **蓝图 grid：**严格遵守 CSS Grid 架构。元素不浮动；它们被精确锚定到 grid 轨道与交叉点。
*   **可见的分区化：**大量使用实线边框（`1px` 或 `2px solid`）来划分不同的信息区域。水平分割线（`<hr>`）经常横跨整个容器宽度，以分隔操作单元。
*   **双态密度：**layout 在极端数据密度（紧密堆叠的 monospace 元数据聚集在一起）与包围宏观排版的广阔经过计算的留白之间交替。
*   **几何：**绝对拒绝 `border-radius`。所有角必须正好 90 度，以强化机械刚性。

## 5. UI component 与符号体系
标准 Web UI 惯例被实用主义、工业化的图形元素所取代。

*   **语法装饰：**利用 ASCII 字符来框定数据点。
    *   *框定：*`[ DELIVERY SYSTEMS ]`、`< RE-IND >`
    *   *方向性：*`>>>`、`///`、`\\\\`
*   **工业标记：**突出整合注册（`®`）、版权（`©`）与商标（`™`）符号，使其作为结构性几何元素而非法律文本发挥作用。
*   **技术资产：**在 grid 交叉点整合十字准线（`+`）、重复的竖线（条形码）、粗水平警示条纹以及随机字符串数据（例如 `REV 2.6`、`UNIT / D-01`），以模拟活跃的机械过程。

## 6. 纹理与后处理效果
为避免设计显得纯数字化，通过 CSS 与 SVG 滤镜将仿真的模拟退化效果工程化地注入前端。

*   **半调与 1 位抖动：**将连续色调图像或大型 serif 字体转换为点阵图案。通过预处理或 CSS `mix-blend-mode: multiply` 叠加层结合 SVG 径向点阵图案实现。
*   **CRT 扫描线：**对于终端界面，在背景上应用 `repeating-linear-gradient` 以模拟水平电子束扫描（例如 `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
*   **机械噪点：**一个应用于 DOM 根节点的全局低 opacity 的 SVG 静电/噪点滤镜，在 dark mode 与 light mode 下引入统一的物理颗粒感。

## 7. Web 工程指令
1.  **grid 确定性：**使用 `display: grid; gap: 1px;` 配合具有对比度的父/子背景色，无需复杂边框声明即可生成数学上完美、如刀刃般纤细的分割线。
2.  **语义严谨：**使用精确的语义标签（`<data>`、`<samp>`、`<kbd>`、`<output>`、`<dl>`）构建 DOM，以准确反映遥测的技术本质。
3.  **排版钳制：**仅为宏观排版实现 CSS `clamp()` 函数，以确保超大文本字号能够强力缩放，同时在各 viewport 下保持结构完整性。
