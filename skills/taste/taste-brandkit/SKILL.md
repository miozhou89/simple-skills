# 品牌套件图像生成技能

你的工作是生成高级品牌套件图像，让它们看起来像是出自一家严谨的识别设计工作室。

输出必须让人感觉：
- 有意图
- 高级
- 极简
- 连贯
- 有策略
- 视觉上昂贵
- 由品牌系统驱动
- 可直接用于演示

禁止生成泛泛的标志。
禁止生成随机的 mockup。
禁止生成杂乱的人工智能情绪板。

在一张图像中创造一个完整的品牌世界。

---

# 参考风格 DNA

期望的视觉质量受到高级品牌指南手册的启发，具有：

- 深炭色的外画布
- 基于 grid 的干净演示看板
- 面板之间强烈的留白间距
- 克制的视觉密度
- 非常稀疏的字体排印
- 大面积负空间
- 电影感的品牌氛围
- 简单但令人难忘的标志符号
- 用作品牌应用的 UI mockup
- 浏览器边框 / 应用头部 / 终端框架
- 以图像为主、带有细微叠加层的面板
- 网版、颗粒、扫描线或印刷纹理
- 几何结构图解
- 小标签与页码细节
- 柔和但有力的强调色
- 标志在多个触点中重复出现
- 每块看板一个强有力的品牌创意

参考图不是一种固定风格。
它们定义的是质量基准、克制程度与演示逻辑。

# 核心原则

一套高级品牌套件不是装饰。

它是关于该品牌为何存在的视觉论证。

每一块生成的看板都必须回答：

1. 这个品牌代表什么？
2. 核心隐喻是什么？
3. 标志如何表达这一点？
4. 系统如何跨 UI、印刷、图像与细节进行延展？
5. 为什么整套东西让人觉得可以被独占拥有？

# 默认输出

除非用户另有说明：

- 生成一张品牌套件总览图像
- 默认 layout：`3 × 3`
- 默认宽高比：`4:3` 或 `16:10`
- 使用干净的演示 grid
- 使用一致的留白间距
- 使用最少的文字
- 让每块面板都感觉彼此关联

允许的 layout：
- `3 × 3` 完整识别系统
- `2 × 3` 电影感品牌手册总览
- `2 × 2` 紧凑的概念看板
- `1 × 3` 横向品牌条带
- `4 × 2` 宽幅联系表 layout
- 按需定制的 layout

# 品牌策略优先

在生成之前，先推断品牌策略。

思考以下方面：

- 品类
- 受众
- 产品功能
- 情感承诺
- 文化定位
- 信任层级
- 视觉世界
- 象征隐喻
- 品牌应该避免什么

视觉系统必须建立在意义之上。

示例：

| 品类 | 核心创意 | 可能的象征逻辑 |
|---|---|---|
| 开发者工具 | 构建、速度、精准、掌控 | 光标、框架、闪电、脚手架、grid |
| 人工智能助手 | 委托、智能、清晰 | 火花、轨道、信号、路径、节点 |
| 安全 | 保护、警觉、边界 | 盾牌、眼睛、封印、受保护的核心 |
| 游戏 / 博彩 | 机会、奖励、张力、速度 | 骰子、宝石、纸牌、信号、奖杯 |
| 语音 AI | 声音、节奏、指令、流动 | 波形、麦克风、球体、语音路径 |
| 合规 | 信任、秩序、规则、保护 | 封印、犬、badge、文件、盾牌 |
| 无人机 / 机器人 | 飞行、掌控、视觉、使命 | 翅膀、猫头鹰、准星、路径、区域 |
| 奢华 / 杂志编辑 | 品味、材质、仪式、克制 | 花押字、封印、纸张、压印、标记 |
| 生产力 | 专注、动量、清晰 | 路径、对勾、积木、日历、光 |

禁止随机挑选符号。

# 标志生成标准

标志必须是专业的。

它应该是：
- 简单的
- 令人难忘的
- 有象征意义的
- 可缩放的
- 可被独占拥有的
- 视觉平衡的
- 与品牌创意相关联的
- 可作为图标、字标、badge、UI 标记与图案使用的

避免：
- 泛泛的闪电形状，除非有充分的理由
- 随机的动物
- 虚假的奢华纹章
- 抄袭著名标志
- 过度复杂的符号
- 剪贴画风格的图标
- 毫无意义的闪光
- 不一致的标志 variant

标志应该让人感觉它来自研究与简化。

---

# 标志概念方法

使用其中一种，或最多组合两种。

## 1. 花押字 + 意义

将品牌首字母与一个隐喻相结合。

示例：
- `K` + 风筝 / 框架 / 方向
- `N` + 路径 / 折叠系统
- `S` + 声波 / 语音流
- `A` + 上升 / 建筑 / 动量

禁止制作无聊的字母图标。
使用负空间、切口、折叠或几何结构。

---

## 2. 产品动作

把产品的主要动作转化为一个符号。

示例：
- 构建 → 框架、脚手架、积木、光标
- 保护 → 盾牌、边界、守望标记
- 转换 → 开关、箭头、变形形状
- 说话 → 波形、麦克风、脉冲
- 狩猎威胁 → 眼睛、猛禽、雷达、踪迹
- 自动化 → 循环、交接、路径

让它抽象且高级，而不是直白。

---

## 3. 隐喻融合

将两个有意义的创意合并为一个简化的标记。

示例：
- 猫头鹰 + 无人机视觉
- 盾牌 + 山
- 月亮 + 波形
- 犬 + 合规封印
- 骰子 + 手游经济
- 光标 + 闪电速度
- 风筝 + 产品框架

融合应该微妙且易读。

---

## 4. 负空间

利用空白来创造巧思。

示例：
- 隐藏的箭头
- 受保护的中心
- 镂空的首字母
- 内部路径
- 折叠的角
- 由交叉形状构成的眼

负空间应该是干脆利落的。

---

## 5. 结构几何

从一个清晰的系统出发创造标记。

使用：
- 圆形
- 对角切割
- grid
- 框架
- 模块化积木
- 层叠 card
- 轨道路径
- 准星
- 有刻度的线稿

可以用一块面板展示结构逻辑。

---

# 看板构图 DNA

一块强有力的品牌套件看板应该像是一个经过策展的序列。

使用：
- 一块大面积、沉静的封面面板
- 一块数字 mockup 面板
- 一块以图像为主导的氛围面板
- 一块系统 / 结构面板
- 一块实体或图标应用面板
- 一块沉静的标语面板

禁止让每块面板都同样喧闹。

看板应该有节奏：
- 沉静
- 功能性
- 情感
- 技术性
- 氛围感
- 细节

---

# 默认 3 × 3 面板系统

若未指定 layout，则使用以下方案：

## 1. 标志封面
大面积标志与字标。
极简标题。
强烈的负空间。

## 2. 标志结构
符号拆解、grid、几何或负空间逻辑。
展示该标记为何存在。

## 3. 数字应用
浏览器边框、应用头部、终端、仪表盘片段或应用图标。

## 4. 品牌精髓
一句简短标语。
大面积、易读的字体排印。
稀疏的构图。

## 5. 色彩系统
色样、gradient 条、色盘、材质色卡或色板 card。

## 6. 字体排印
大面积字体样张、字母表行，或主 / 次字体配对。

## 7. 实体应用
card、文件夹、badge、海报、标签、封印、包装或实物 mockup。

## 8. 图像方向
电影感风景、产品裁切、网版海报、杂志编辑场景、材质纹理。

## 9. 系统细节
UI 徽片、输入栏、命令行、图标行、badge 系统、component 条带、图案细节。

---

# 2 × 3 参考风格 layout

对于类似上传参考图的看板，使用：

1. **标志 / 字标**
   - 居中或偏移
   - 极度极简

2. **浏览器 / 产品界面**
   - 浏览器栏、应用框架、prompt 输入框或 URL 字段

3. **命令 / 功能面板**
   - 终端、prompt 栏、输入状态、安装命令、仪表盘片段

4. **氛围 / 传播画面**
   - 网版风景、电影感图像、产品世界视觉或经过艺术指导的照片

5. **象征 / 结构 / badge**
   - 靶心中的标志符号、封印、几何框架、图标结构

6. **标语 / 系统承诺**
   - 一行短句
   - 大字
   - 沉静的背景

此 layout 应该像一份高级迷你手册。

# 视觉模式

根据品牌进行选择。

## 暗黑开发者 / 构建者

用于：
开发者工具、编码代理、基础设施、自动化、AI 构建者。

视觉线索：
- 近黑面板
- monospace 强调
- 命令行
- 终端窗口
- prompt 栏
- 细微的 grid
- 青色、蓝色、珊瑚色或青柠色强调
- 如合适，可用像素或 CRT 纹理

标志逻辑：
- 光标 + 框架
- 闪电 + 构建速度
- 脚手架 + 花押字
- 终端字形 + 符号
- 模块化结构标记

情绪：
精准、锐利、自信、构建者原生。

---

## 暗黑产品 / 运营者

用于：
商业工具、增长工具、销售代理、自动化、生产力。

视觉线索：
- 黑色 / 深红 / 琥珀色
- 发光的 UI 徽片
- card 系统
- 分段式流程
- 图标行
- 奖励 / 进度母题
- 极简的 hero 文字

标志逻辑：
- 信号、礼物、路径、运营者标记、开关、循环、指令系统

情绪：
快速、可操作、战术性、高级。

---

## 暗黑自然 / 沉静系统

用于：
战略、旅行、健康、气候、沉静的高级 SaaS。

视觉线索：
- 深绿
- 青柠色强调
- 雾气风景
- 图像 UI 圆形
- 柔和的叠加层
- 沉静的页面标签
- 暗色杂志编辑 grid

标志逻辑：
- 路径、叶、月亮、地平线、罗盘、入口、折叠标记

情绪：
沉静、值得信赖、专注。

---

## 暗黑安全 / 威胁情报

用于：
安全、合规、监控、网络产品。

视觉线索：
- 黑色 / 海军蓝
- 盾牌形态
- 雷达线
- 威胁标签
- 细微的运动轨迹
- 红色 / 蓝色告警徽片
- 受控的 gradient

标志逻辑：
- 盾牌、猛禽、眼、守望、边界、受保护的核心

情绪：
严肃、警觉、精准。

---

## 浅色杂志编辑 / 合规

用于：
法律、隐私、合规、文件、信任型品牌。

视觉线索：
- 暖象牙色
- 纸张纹理
- 小号 serif 标签
- 封印 / badge
- 色轮 / 色板对象
- 沉静的文具
- 深蓝、红色、金色强调

标志逻辑：
- 封印、犬、盾牌、文件、印章、花押字

情绪：
值得信赖、精炼、具有机构感但又现代。

---

## 奢华 / 美妆 / 时尚

用于：
美妆、时尚、酒店业、高端服务。

视觉线索：
- 象牙色 / 石色 / 浓缩咖啡色
- serif 字标
- 优雅的花押字
- 纸张颗粒
- 压印
- 产品标签
- 杂志编辑式裁切
- 柔和的 shadow

标志逻辑：
- 花押字、封印、花瓣、容器、仪式物件、精炼的字体标记

情绪：
有品味、成熟、昂贵。

---

## 语音 / 沟通

用于：
语音 AI、聊天、助手、语音、音频。

视觉线索：
- 深靛蓝
- 淡紫光晕
- 波形
- 麦克风母题
- 手机裁切
- 命令输入
- 应用图标

标志逻辑：
- 波形 + 首字母
- 声音球体
- 语音路径
- 麦克风抽象
- 脉冲环

情绪：
流动、智能、亲密。

---

## 文化 / 实验性

用于：
音乐、创意工具、活动、泛游戏、文化产品。

视觉线索：
- 网版
- CRT 纹理
- 模拟印刷
- 大胆的强调色

- 出人意料的图像裁切

标志逻辑：
- 定制字标
- 有态度的图标
- 象征性吉祥物
- 受印刷启发的标记

情绪：
令人难忘、有创意、但仍然受控。

# 高级细节语言

使用如下细节：
- 小号页码
- 极小的页脚标签
- 精准的对齐标记
- 结构线
- 细微的准星 grid
- 细线
- 浏览器栏
- 圆角矩形
- 图像遮罩
- 柔和的 shadow
- 低 opacity 纹理
- 网版图像处理
- 一个高亮的词
- 一枚强调徽片
- 一个强烈的图标状态

禁止过度使用它们。

高级细节应该奖励那些看得更仔细的人。

---

# 文字规则

使用非常少的文字。

好文字：
- 品牌名
- 一句标语
- 一个 URL
- 一条命令
- 2–5 个分区标签
- 短小的 UI 徽片

坏文字：
- 长段落
- 极小、虚假的正文副本
- 大量菜单项
- lorem ipsum
- 密集的解释
- 无法辨认的标签

文字应该足够大、足够稀疏，以便良好地呈现。

---

# 标语风格

标语应该简短且具体。

好：
- "What will you build today?"
- "Nothing random."
- "Your network. Our watch."
- "Build better."
- "On guard."
- "Every mission under control."
- "Everything operators need."
- "Clarity builds confidence."

避免：
- 泛泛的企业口号
- 冗长的营销文案
- 术语堆砌
- 虚假的励志空话

---

# 图像方向

图像应该感觉是经过艺术指导的。

使用：
- 电影感的群山
- 黄昏天空
- 带有品牌叠加层的风景
- 网版云层
- CRT 屏幕场景
- 暗色产品特写
- 戏剧性的物体裁切
- 有纹理的纸张背景
- 有氛围感的建筑
- 抽象但受控的视觉系统

避免：
- 泛泛的图库人物
- 随机的办公室照片
- 陈词滥调的机器人图像
- 过度拥挤的场景
- 不相关的图像

图像应该与色板和隐喻相匹配。

---

# mockup 方向

mockup 应该极简且可信。

使用：
- 浏览器边框
- URL 栏
- 终端窗口
- 命令 prompt
- 应用图标
- 手机边角裁切
- card 堆叠
- badge
- 封印
- 文件夹
- UI 徽片
- 仪表盘片段
- 输入栏
- 产品标签

避免：
- 数据过多的完整虚假仪表盘
- 廉价的光面 mockup
- 随机的设备堆砌
- 拥挤的应用界面
- 过多的图标

mockup 是识别应用，而不是功能演示。

---

# 色彩纪律

使用一个主导的色板。

默认：
- 基础色
- 主强调色
- 次强调色
- 中性色

好的参考风格色板：
- 黑 + 青 + 柔和的珊瑚色
- 黑 + 红 + 奶油色 + 蓝
- 森林绿 + 青柠 + 雾灰
- 海军蓝 + 白 + 钢色
- 象牙色 + 深蓝 + 红 + 金
- 黑 + 淡紫 + 柔紫
- 黑 + 琥珀 + 红
- 炭色 + 白 + 浅蓝

规则：
- 强调色必须在各面板间重复出现
- 除非有要求，禁止随机的彩虹色
- 除非合适，禁止泛泛的紫蓝色 AI 光晕
- 一种强调色即可承载整套系统

---

# 反泛化规则

禁止制作：
- 随机漂浮的图标
- 泛泛的创业公司 gradient
- 过度设计的标志
- 毫无意义的色块
- 杂乱的 layout 拼贴
- 虚假的微型 UI
- 不一致的标志符号
- 过多的颜色
- 廉价霓虹
- 模板化的品牌看板
- 企业 PowerPoint 幻灯片
- 毫无灵魂的 SaaS 仪表盘

让设计更沉静、更锐利、更有意图。

# 参考图使用

当用户提供参考图时：

提取：
- layout 节奏
- grid 风格
- 间距
- 字体排印尺度
- 视觉密度
- 标志位置
- 文字数量
- 图像处理
- 强调色逻辑
- 品牌系统行为

- 干净的
- 有策略的
- 有象征意义的

- 连贯的

- 易于实施的
